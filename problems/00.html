문제 0

환경 띄우기: SHOW TABLES 10행

담당 전원 체크리스트 선행 없음

PROBLEM · 문제

Docker(또는 Plan B인 수업용 MySQL)로 vuln_mgmt DB를 띄우고, Workbench로 접속해 스키마와 seed가 들어 있는지 확인한다.

CHECKLIST · 확인 항목 (체크하면 이 브라우저에 저장돼요)

NOTE · 노트

  • 포트 3306은 수업용 MySQL이 쓰고 있을 가능성이 높아요. .env의 MYSQL_PORT=3307로 바꾸고 docker compose up -d를 다시 실행하세요.
  • 10행이 아니면 schema.sql이 중간에 멈춘 거예요. 오류 메시지를 단톡에 올려 주세요.

HINT · 힌트 (관련 수업)

정답 대신 다시 볼 수업 주차예요. 수업에 없던 문법은 공통 가이드의 미니 사전에 있어요.

  • 1주차 Workbench 사용법
  • 2주차 CREATE DATABASE·USE

JUDGE · 채점 방법

체크리스트 문제라 맞음/틀림을 매기지 않아요. 위 항목을 직접 확인하고 체크하세요. 채점기를 실행하면 자동으로 확인할 수 있는 항목은 결과를 같이 보여줘요.

python judge/judge.py 0

RESET · 이 단계 시작 상태로 되돌리기

schema·seed 다시 적재 (공통 가이드의 명령, Plan B는 Workbench에서 schema.sql → seed.sql 실행)

# Docker (레포 루트, 기존 데이터는 모두 지워져요)
docker compose exec db sh -c 'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 < /work/db/schema.sql && mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 < /work/db/seed.sql'

# Plan B (수업용 MySQL): Workbench에서 db/schema.sql 열고 실행(⚡) → db/seed.sql 열고 실행(⚡)
