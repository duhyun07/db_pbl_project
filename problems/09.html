문제 9

인덱스 전후 EXPLAIN 비교 (type, key, rows)

담당 ②④ 체크리스트 선행 #2, #5

PROBLEM · 문제

대량 가상 데이터에서 인덱스가 없는 일반 컬럼으로 거르는 쿼리를 골라, 인덱스를 추가하기 전과 후의 EXPLAIN과 실행 시간을 비교한다.

CHECKLIST · 확인 항목 (체크하면 이 브라우저에 저장돼요)

NOTE · 노트

  • FK·UNIQUE 컬럼(system_id, cve_id, assignee_id 등)에는 이미 인덱스가 있어서 전후 차이가 안 나요. cvss_score, status, due_date 같은 일반 컬럼으로 실험하세요.
  • 후보 목록은 vuln-mgmt docs/design_decisions.md §6.
  • rows는 추정치예요. 실제 시간은 EXPLAIN ANALYZE나 여러 번 잰 평균으로 비교해요.
  • 실험한 인덱스는 내 로컬 DB에서만. 스키마 반영은 ①이 결정해요.

HINT · 힌트 (관련 수업)

정답 대신 다시 볼 수업 주차예요. 수업에 없던 문법은 공통 가이드의 미니 사전에 있어요.

  • 7주차 EXPLAIN (type, key, rows=추정치)
  • 12주차 CREATE INDEX, PK·FK·UK 자동 인덱스

JUDGE · 채점 방법

체크리스트 문제라 맞음/틀림을 매기지 않아요. 위 항목을 직접 확인하고 체크하세요.
