2수집 대상 고르기

① 이 단계에서 만드는 것

data/cve_list.csv — 수집할 CVE 10~15건 (후보 표는 20건 정도 만들고 골라요).

② 왜 이렇게 하나

Ubuntu 24.04(noble)에서 released(수정 패키지가 나옴)인 CVE여야 "패치 대상 → 조치 → 완료" 시나리오가 성립해요. 점수가 고르게 퍼져 있어야 ②의 분포 분석이 의미 있고, 점수 없는 CVE가 1~2개 있어야 NULL 처리를 보여줄 수 있어요.

③ 방법과 코드

웹에서 보기 (확인한 주소): https://ubuntu.com/security/cves?package=openssh&version=noble&status=released (openssh 자리에 apache2)

JSON으로 뽑기 — 같은 조건의 JSON API를 쓰는 1회용 스크립트예요 (레포에 안 남겨도 돼요).

"""Ubuntu에서 noble(24.04) 상태가 released인 CVE 후보를 뽑아 본다. (후보 고르기용, 1회성)

실행: python data/list_candidates.py openssh
      python data/list_candidates.py apache2
"""
import sys

import requests

package = sys.argv[1] if len(sys.argv) > 1 else "openssh"
resp = requests.get(
    "https://ubuntu.com/security/cves.json",
    params={"package": package, "version": "noble", "status": "released",
            "limit": 20, "offset": 0},          # limit은 최대 20. 더 보려면 offset을 20, 40...으로
    headers={"User-Agent": "vuln-mgmt-student-project"},
    timeout=60,
)
resp.raise_for_status()
data = resp.json()
print(f"{package}: 전체 {data['total_results']}건 중 {len(data['cves'])}건")
print("cve_id\tpriority\tcvss3\tnoble 수정 버전")
for cve in data["cves"]:
    fixed = ""
    for pkg in cve["packages"]:
        if pkg["name"] != package:
            continue
        for st in pkg["statuses"]:
            if st["release_codename"] == "noble":
                fixed = st["description"]
    print(f"{cve['id']}\t{cve['priority']}\t{cve['cvss3']}\t{fixed}")

3collect_cve.py — 원본 수집

① 이 단계에서 만드는 것

data/collect_cve.py → 실행하면 data/raw/nvd/, data/raw/ubuntu/에 CVE마다 JSON 파일 1개씩, 실패 목록 data/raw/failed.csv.

② 왜 이렇게 하나

  • 원본을 가공 없이 저장: 추출 규칙이 바뀌어도 다시 받을 필요 없이 6단계만 다시 돌리면 돼요.
  • 요청 간격(sleep)과 재시도: NVD는 API 키 없이 쓰면 요청 횟수 제한이 있어요. 6초 간격이면 여유 있게 안전해요.
  • 이미 받은 파일은 건너뛰기: 중간에 실패해도 다시 실행하면 실패한 것만 받아요.

③ 코드

"""NVD와 Ubuntu에서 CVE 원본 JSON을 받아 data/raw/에 저장한다.

실행: python data/collect_cve.py
입력: data/cve_list.csv   (cve_id, software, source_url, memo)
출력: data/raw/nvd/<CVE>.json, data/raw/ubuntu/<CVE>.json, data/raw/failed.csv
"""
import csv
import json
import time
from pathlib import Path

import requests

DATA_DIR = Path(__file__).resolve().parent
RAW_DIR = DATA_DIR / "raw"
NVD_URL = "https://services.nvd.nist.gov/rest/json/cves/2.0"
UBUNTU_URL = "https://ubuntu.com/security/cves/{cve_id}.json"

SLEEP_SECONDS = 6        # API 키 없이 NVD를 쓸 때 요청 사이 간격 (넉넉하게)
MAX_RETRY = 3            # 실패하면 몇 번까지 다시 시도할지
HEADERS = {"User-Agent": "vuln-mgmt-student-project"}


def fetch_json(url, params=None):
    """URL에서 JSON을 받는다. 실패하면 MAX_RETRY번까지 간격을 늘려 가며 다시 시도한다."""
    for attempt in range(1, MAX_RETRY + 1):
        try:
            resp = requests.get(url, params=params, headers=HEADERS, timeout=30)
            if resp.status_code == 200:
                return resp.json()
            print(f"  HTTP {resp.status_code} (시도 {attempt}/{MAX_RETRY})")
        except requests.RequestException as e:
            print(f"  요청 오류: {e} (시도 {attempt}/{MAX_RETRY})")
        time.sleep(SLEEP_SECONDS * attempt)   # 6초 → 12초 → 18초
    return None


def save_json(path, data):
    path.parent.mkdir(parents=True, exist_ok=True)
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)


def collect_one(cve_id):
    """CVE 1건을 NVD, Ubuntu에서 받아 저장한다. 둘 다 성공하면 True."""
    ok = True

    nvd_path = RAW_DIR / "nvd" / f"{cve_id}.json"
    if nvd_path.exists():
        print("  NVD: 이미 있음, 건너뜀")
    else:
        data = fetch_json(NVD_URL, params={"cveId": cve_id})
        if data and data.get("totalResults", 0) > 0:
            save_json(nvd_path, data)
            print("  NVD: 저장")
        else:
            print("  NVD: 실패 또는 결과 없음")
            ok = False
        time.sleep(SLEEP_SECONDS)

    ubuntu_path = RAW_DIR / "ubuntu" / f"{cve_id}.json"
    if ubuntu_path.exists():
        print("  Ubuntu: 이미 있음, 건너뜀")
    else:
        data = fetch_json(UBUNTU_URL.format(cve_id=cve_id))
        if data and data.get("id") == cve_id:
            save_json(ubuntu_path, data)
            print("  Ubuntu: 저장")
        else:
            print("  Ubuntu: 실패 또는 결과 없음")
            ok = False
        time.sleep(1)

    return ok


def main():
    with open(DATA_DIR / "cve_list.csv", encoding="utf-8") as f:
        rows = list(csv.DictReader(f))

    failed = []
    for i, row in enumerate(rows, start=1):
        cve_id = row["cve_id"].strip()
        print(f"[{i}/{len(rows)}] {cve_id}")
        if not collect_one(cve_id):
            failed.append(cve_id)

    # 실패한 CVE는 파일로 남긴다. 다시 실행하면 이미 받은 파일은 건너뛰므로 실패한 것만 재시도된다.
    with open(RAW_DIR / "failed.csv", "w", encoding="utf-8", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["cve_id"])
        for cve_id in failed:
            writer.writerow([cve_id])

    print(f"완료: 성공 {len(rows) - len(failed)}건, 실패 {len(failed)}건")
    if failed:
        print("실패 목록: data/raw/failed.csv")


if __name__ == "__main__":
    main()

4원본 JSON 구조 읽기

① 이 단계에서 만드는 것

파일은 없어요. 받은 JSON에서 우리 컬럼에 들어갈 값이 어느 경로에 있는지 찾아요. 결과는 5단계의 매핑표가 돼요.

② 왜 이렇게 하나

NVD는 CVE의 설명·점수·공개일을, Ubuntu는 릴리스별 패키지 상태·수정 버전·USN·우선순위를 줘요. 한 곳에서 다 받을 수 없어서 두 원본을 합쳐야 하고, 그 "합치는 규칙"이 우리 정형화 작업의 핵심이에요.

6load_db.py — DB 적재

① 이 단계에서 만드는 것

data/load_db.py — 원본 JSON에서 값을 뽑아 software → vulnerabilities → cve_package_status 순서로 적재.

② 왜 이렇게 하나

  • 순서: cve_package_status는 vulnerabilities와 software를 FK로 참조해서, 부모가 먼저 있어야 들어가요.
  • INSERT … ON DUPLICATE KEY UPDATE: 이미 있는 PK면 값만 갱신해서, 몇 번을 다시 실행해도 중복이 안 생겨요. (AS new 별칭은 MySQL 8.0.19부터 쓰는 방식이에요.)
  • executemany: 행 목록을 한 번에 넘겨요.
  • 트랜잭션: 세 테이블을 한 번에 commit. 중간에 실패하면 rollback되어 "반만 들어간 상태"가 안 생겨요.

③ 코드

"""data/raw/의 원본 JSON에서 값을 뽑아 DB에 적재한다. 여러 번 실행해도 안전하다.

실행: python data/load_db.py
적재 순서(FK 때문): software → vulnerabilities → cve_package_status
"""
import csv
import json
import os
from datetime import datetime
from pathlib import Path

import pymysql
from dotenv import load_dotenv

DATA_DIR = Path(__file__).resolve().parent
RAW_DIR = DATA_DIR / "raw"
load_dotenv(DATA_DIR.parent / ".env")

NVD_URL = "https://services.nvd.nist.gov/rest/json/cves/2.0?cveId={cve_id}"
UBUNTU_URL = "https://ubuntu.com/security/cves/{cve_id}.json"

# software 테이블에 넣을 값 (source_package → 표시 이름)
SOFTWARE = {"apache2": "Apache HTTP Server", "openssh": "OpenSSH"}

# Ubuntu 코드명 → 릴리스 번호 (DB에는 번호만 넣는다)
RELEASES = {"noble": "24.04", "jammy": "22.04"}

# DB의 cve_package_status.status ENUM에 있는 값만 적재한다.
# Ubuntu JSON에는 DNE(해당 릴리스에 패키지 없음), needs-triage 같은 값도 있는데 건너뛰고 로그를 남긴다.
ALLOWED_STATUS = {"needed", "released", "not-affected", "deferred", "ignored"}
ALLOWED_PRIORITY = {"negligible", "low", "medium", "high", "critical"}

# CVSS를 고르는 순서: 3.1 → 3.0 → 4.0. 같은 버전 안에서는 NVD(Primary)를 먼저.
CVSS_KEYS = ["cvssMetricV31", "cvssMetricV30", "cvssMetricV40"]


def connect():
    return pymysql.connect(
        host=os.getenv("MYSQL_HOST", "127.0.0.1"),
        port=int(os.getenv("MYSQL_PORT", "3306")),
        user=os.getenv("MYSQL_USER"),
        password=os.getenv("MYSQL_PASSWORD"),
        database=os.getenv("MYSQL_DATABASE", "vuln_mgmt"),
        charset="utf8mb4",
        autocommit=False,
    )


def load_json(path):
    with open(path, encoding="utf-8") as f:
        return json.load(f)


def pick_cvss(metrics):
    """NVD metrics에서 CVSS 하나를 고른다. 없으면 None."""
    for key in CVSS_KEYS:
        candidates = metrics.get(key, [])
        if not candidates:
            continue
        # Primary(NVD가 직접 매긴 점수)를 먼저, 없으면 첫 번째(Secondary, CNA가 매긴 점수)
        primary = [m for m in candidates if m.get("type") == "Primary"]
        chosen = primary[0] if primary else candidates[0]
        data = chosen.get("cvssData", {})
        return {
            "score": data.get("baseScore"),
            "version": data.get("version"),
            "vector": data.get("vectorString"),
            "source": "NVD" if chosen.get("type") == "Primary" else "NVD-secondary",
        }
    return None


def extract_vulnerability(cve_id):
    """원본 JSON 2개에서 vulnerabilities 1행을 만든다."""
    nvd = load_json(RAW_DIR / "nvd" / f"{cve_id}.json")
    ubuntu = load_json(RAW_DIR / "ubuntu" / f"{cve_id}.json")
    cve = nvd["vulnerabilities"][0]["cve"]

    # 영어 설명 하나
    description = None
    for d in cve.get("descriptions", []):
        if d.get("lang") == "en":
            description = d.get("value")
            break

    # "2024-07-01T13:15:06.467" → date(2024, 7, 1)
    published = cve.get("published")
    published_date = datetime.fromisoformat(published).date() if published else None

    cvss = pick_cvss(cve.get("metrics", {}))
    if cvss is None:
        # NVD에 점수가 없으면 Ubuntu의 CVSS 3 점수를 쓴다. 그것도 없으면 전부 None(NULL).
        v3 = (ubuntu.get("impact") or {}).get("baseMetricV3", {}).get("cvssV3", {})
        if v3.get("baseScore") is not None:
            cvss = {"score": v3.get("baseScore"), "version": v3.get("version"),
                    "vector": v3.get("vectorString"), "source": "Ubuntu"}
        else:
            cvss = {"score": None, "version": None, "vector": None, "source": None}

    priority = ubuntu.get("priority")
    if priority not in ALLOWED_PRIORITY:
        priority = None   # untriaged 등은 NULL

    return (cve_id, description, published_date, cvss["score"], cvss["version"],
            cvss["vector"], cvss["source"], priority, NVD_URL.format(cve_id=cve_id))


def find_usn(ubuntu, codename, package, fixed_version):
    """수정 버전이 들어 있는 USN 번호를 찾는다. 없으면 None."""
    for notice in ubuntu.get("notices", []):
        for pkg in notice.get("release_packages", {}).get(codename, []):
            if pkg.get("is_source") and pkg.get("name") == package and pkg.get("version") == fixed_version:
                return notice.get("id")
    return None


def extract_package_status(cve_id, software_ids, skipped):
    """Ubuntu JSON에서 cve_package_status 행 목록을 만든다."""
    ubuntu = load_json(RAW_DIR / "ubuntu" / f"{cve_id}.json")
    rows = []
    for pkg in ubuntu.get("packages", []):
        package = pkg.get("name")
        if package not in software_ids:
            continue   # openssh-ssh1처럼 우리가 관리하지 않는 패키지
        for st in pkg.get("statuses", []):
            codename = st.get("release_codename")
            if codename not in RELEASES:
                continue
            status = st.get("status")
            if status not in ALLOWED_STATUS:
                skipped.append((cve_id, package, codename, status))
                continue
            fixed_version = st.get("description") if status == "released" else None
            usn_id = find_usn(ubuntu, codename, package, fixed_version) if fixed_version else None
            rows.append((cve_id, software_ids[package], RELEASES[codename], status,
                         fixed_version, usn_id, UBUNTU_URL.format(cve_id=cve_id)))
    return rows


def main():
    with open(DATA_DIR / "cve_list.csv", encoding="utf-8") as f:
        cve_ids = [r["cve_id"].strip() for r in csv.DictReader(f)]
    # 원본 파일이 둘 다 있는 CVE만 적재
    cve_ids = [c for c in cve_ids
               if (RAW_DIR / "nvd" / f"{c}.json").exists() and (RAW_DIR / "ubuntu" / f"{c}.json").exists()]

    conn = connect()
    try:
        with conn.cursor() as cur:
            # 1) software
            cur.executemany(
                "INSERT INTO software (name, source_package) VALUES (%s, %s) AS new "
                "ON DUPLICATE KEY UPDATE name = new.name",
                [(name, pkg) for pkg, name in SOFTWARE.items()],
            )
            cur.execute("SELECT source_package, software_id FROM software")
            software_ids = dict(cur.fetchall())

            # 2) vulnerabilities
            vuln_rows = [extract_vulnerability(c) for c in cve_ids]
            cur.executemany(
                """INSERT INTO vulnerabilities
                     (cve_id, description, published_date, cvss_score, cvss_version,
                      cvss_vector, cvss_source, ubuntu_priority, source_url)
                   VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s) AS new
                   ON DUPLICATE KEY UPDATE
                     description = new.description, published_date = new.published_date,
                     cvss_score = new.cvss_score, cvss_version = new.cvss_version,
                     cvss_vector = new.cvss_vector, cvss_source = new.cvss_source,
                     ubuntu_priority = new.ubuntu_priority, source_url = new.source_url""",
                vuln_rows,
            )

            # 3) cve_package_status
            skipped = []
            cps_rows = []
            for c in cve_ids:
                cps_rows.extend(extract_package_status(c, software_ids, skipped))
            cur.executemany(
                """INSERT INTO cve_package_status
                     (cve_id, software_id, ubuntu_release, status, fixed_version, usn_id, source_url)
                   VALUES (%s, %s, %s, %s, %s, %s, %s) AS new
                   ON DUPLICATE KEY UPDATE
                     status = new.status, fixed_version = new.fixed_version,
                     usn_id = new.usn_id, source_url = new.source_url""",
                cps_rows,
            )
        conn.commit()   # 세 테이블을 한 트랜잭션으로: 중간에 실패하면 아무것도 안 들어간다
        print(f"software {len(software_ids)}건, vulnerabilities {len(vuln_rows)}건, "
              f"cve_package_status {len(cps_rows)}건 적재")
        for s in skipped:
            print("  건너뜀 (ENUM에 없는 상태):", s)
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()


if __name__ == "__main__":
    main()

"""원본 JSON에서 다시 뽑은 값과 DB에 들어간 값을 비교한다.

실행: python data/validate_db.py
출력: CVE별 일치/불일치. 결과를 docs/data_validation.md 표에 옮겨 적는다.
"""
import csv
from decimal import Decimal

from load_db import (DATA_DIR, RAW_DIR, connect, extract_package_status,
                     extract_vulnerability)

VULN_COLUMNS = ["cve_id", "description", "published_date", "cvss_score", "cvss_version",
                "cvss_vector", "cvss_source", "ubuntu_priority", "source_url"]


def same(a, b):
    """DB의 Decimal(9.8)과 JSON의 float(9.8)처럼 타입만 다른 경우는 같다고 본다."""
    if isinstance(a, Decimal) or isinstance(b, Decimal):
        return a is not None and b is not None and Decimal(str(a)) == Decimal(str(b))
    return a == b


def main():
    with open(DATA_DIR / "cve_list.csv", encoding="utf-8") as f:
        cve_ids = [r["cve_id"].strip() for r in csv.DictReader(f)]

    conn = connect()
    problems = 0
    with conn.cursor() as cur:
        cur.execute("SELECT source_package, software_id FROM software")
        software_ids = dict(cur.fetchall())

        for cve_id in cve_ids:
            if not (RAW_DIR / "nvd" / f"{cve_id}.json").exists():
                print(f"{cve_id}: 원본 없음 (수집 실패)")
                problems += 1
                continue

            expected = extract_vulnerability(cve_id)
            cur.execute(f"SELECT {', '.join(VULN_COLUMNS)} FROM vulnerabilities WHERE cve_id = %s", (cve_id,))
            actual = cur.fetchone()
            if actual is None:
                print(f"{cve_id}: DB에 없음")
                problems += 1
                continue
            diffs = [col for col, e, a in zip(VULN_COLUMNS, expected, actual)
                     if not (e is None and a is None) and not same(e, a)]

            expected_cps = sorted(extract_package_status(cve_id, software_ids, []))
            cur.execute(
                "SELECT cve_id, software_id, ubuntu_release, status, fixed_version, usn_id, source_url "
                "FROM cve_package_status WHERE cve_id = %s ORDER BY software_id, ubuntu_release",
                (cve_id,))
            actual_cps = sorted(cur.fetchall())
            if expected_cps != actual_cps:
                diffs.append("cve_package_status")

            score = actual[3] if actual[3] is not None else "NULL"
            print(f"{cve_id}: {'일치' if not diffs else '불일치 ' + str(diffs)}"
                  f" (cvss {score}, 패키지 상태 {len(actual_cps)}행)")
            problems += bool(diffs)
    conn.close()
    print(f"검사 {len(cve_ids)}건, 문제 {problems}건")


if __name__ == "__main__":
    main()

8시연용 가상 데이터 (generate_synthetic.py --mode demo)

① 이 단계에서 만드는 것

data/generate_synthetic.py — 가상 서버·설치 패키지·담당자·조치 건·이력을 만드는 스크립트. 이 단계는 --mode demo(서버 6대).

② 왜 이렇게 하나

  • random.seed 고정: 누가 몇 번을 돌려도 같은 데이터가 나와서 ②의 검증표와 ③의 화면 숫자가 팀원마다 같아요.
  • 시나리오를 의도적으로: 기한 초과, 완료율 0%·100% 서버, 같은 CVE가 여러 서버에, 담당자 없음, 이력 여러 번 — ②·③이 보여줄 장면을 데이터가 보장해요.
  • 설치 버전은 지어내지 않기: 수집한 실제 수정 버전 문자열 중에서 골라요(가장 오래된 것 = 영향 많음, 최신 = 영향 적음). 그러면 영향 판정(10단계)도 진짜 버전 비교로 돌아가요.
  • 상태를 단계별로 UPDATE: 처음엔 모두 open으로 넣고 in_progress → patched처럼 UPDATE해야 ①의 트리거가 이력을 단계마다 남겨요. 이때도 updated_by를 반드시 같이 넣어요.

"""가상 데이터(서버, 설치 패키지, 담당자, 조치 건, 이력)를 만든다.

실행:
  python data/generate_synthetic.py --mode demo                 # 시연용: 서버 6대, 시나리오 포함
  python data/generate_synthetic.py --mode bench --servers 3000 # 성능용: 서버 수천 대

전제: load_db.py로 실제 데이터(software, vulnerabilities, cve_package_status)를 먼저 적재해 둔다.
주의: 실행할 때마다 가상 데이터 테이블 5개를 비우고 다시 만든다. 실제 데이터 테이블은 건드리지 않는다.
"""
import argparse
import os
import random
from datetime import date, datetime, timedelta
from pathlib import Path

import pymysql
from debian.debian_support import Version
from dotenv import load_dotenv

load_dotenv(Path(__file__).resolve().parent.parent / ".env")

SEED = 42
RELEASE = "24.04"
STAFF = [   # 가상 담당자
    (1, "김보안", "보안팀", "kim.security@example.com"),
    (2, "이서버", "인프라팀", "lee.infra@example.com"),
    (3, "박운영", "운영팀", "park.ops@example.com"),
    (4, "최개발", "개발팀", "choi.dev@example.com"),
]


def connect():
    return pymysql.connect(
        host=os.getenv("MYSQL_HOST", "127.0.0.1"),
        port=int(os.getenv("MYSQL_PORT", "3306")),
        user=os.getenv("MYSQL_USER"),
        password=os.getenv("MYSQL_PASSWORD"),
        database=os.getenv("MYSQL_DATABASE", "vuln_mgmt"),
        charset="utf8mb4",
        autocommit=False,
    )


def load_real_data(cur):
    """실제 데이터에서 소프트웨어별 CVE 목록과 버전 후보를 읽는다."""
    cur.execute("SELECT software_id, source_package FROM software")
    software = dict(cur.fetchall())
    cur.execute(
        "SELECT cve_id, software_id, status, fixed_version FROM cve_package_status "
        "WHERE ubuntu_release = %s AND status IN ('released', 'needed')",
        (RELEASE,),
    )
    cves = {sid: [] for sid in software}
    versions = {sid: set() for sid in software}
    for cve_id, sid, status, fixed in cur.fetchall():
        cves[sid].append((cve_id, status, fixed))
        if fixed:
            versions[sid].add(fixed)
    # 설치 버전은 지어내지 않고, 수집한 실제 수정 버전 중에서 고른다. 오래된 순으로 정렬.
    versions = {sid: sorted(v, key=Version) for sid, v in versions.items()}
    for sid, v in versions.items():
        if not v:
            raise SystemExit(f"{software[sid]}의 released 데이터가 없어요. load_db.py를 먼저 실행하세요.")
    return software, cves, versions


def is_affected(installed, status, fixed):
    """설치 버전이 이 CVE의 영향을 받는지. 문자열 비교가 아니라 Debian 버전 비교를 쓴다."""
    if status == "needed":          # 아직 수정 버전이 없음 → 설치된 버전은 모두 영향
        return True
    return Version(installed) < Version(fixed)


def reset_synthetic(conn):
    """가상 데이터 테이블만 비운다. FK 때문에 자식 테이블부터 지운다."""
    with conn.cursor() as cur:
        cur.execute("DELETE FROM system_vulnerabilities")   # patch_history는 CASCADE로 같이 지워짐
        cur.execute("DELETE FROM installed_software")
        cur.execute("DELETE FROM systems")
        cur.execute("DELETE FROM staff")
    conn.commit()
    with conn.cursor() as cur:
        for table in ("system_vulnerabilities", "patch_history", "systems", "staff"):
            cur.execute(f"ALTER TABLE {table} AUTO_INCREMENT = 1")   # 누가 돌려도 같은 ID가 나오게


def make_demo(conn, software, cves, versions):
    rng = random.Random(SEED)
    sid = {pkg: s for s, pkg in software.items()}      # 'apache2' → software_id
    old = {s: v[0] for s, v in versions.items()}       # 가장 오래된 버전 → 영향받는 CVE가 많음
    new = {s: v[-1] for s, v in versions.items()}      # 가장 최신 버전 → released CVE에는 영향 없음

    # (system_id, hostname, environment, {software_id: 설치 버전}, 시나리오)
    servers = [
        (1, "web-prod-01", "prod",    {sid["apache2"]: old[sid["apache2"]], sid["openssh"]: old[sid["openssh"]]}, "mixed"),
        (2, "web-prod-02", "prod",    {sid["apache2"]: old[sid["apache2"]], sid["openssh"]: new[sid["openssh"]]}, "mixed"),
        (3, "web-stg-01",  "staging", {sid["apache2"]: new[sid["apache2"]], sid["openssh"]: old[sid["openssh"]]}, "mixed"),
        (4, "db-prod-01",  "prod",    {sid["openssh"]: old[sid["openssh"]]},                                     "all_open"),     # 완료율 0%
        (5, "dev-01",      "dev",     {sid["openssh"]: old[sid["openssh"]]},                                     "all_patched"),  # 완료율 100%
        (6, "dev-02",      "dev",     {sid["apache2"]: new[sid["apache2"]], sid["openssh"]: new[sid["openssh"]]}, "mixed"),
    ]
    mixed_cycle = ["open", "in_progress", "patched", "risk_accepted", "open", "patched"]
    today = date.today()
    now = datetime.now().replace(microsecond=0)

    with conn.cursor() as cur:
        cur.executemany("INSERT INTO staff (staff_id, name, team, email) VALUES (%s, %s, %s, %s)", STAFF)
        cur.executemany(
            "INSERT INTO systems (system_id, hostname, ubuntu_release, environment) VALUES (%s, %s, %s, %s)",
            [(s[0], s[1], RELEASE, s[2]) for s in servers],
        )
        cur.executemany(
            "INSERT INTO installed_software (system_id, software_id, installed_version) VALUES (%s, %s, %s)",
            [(s[0], soft, ver) for s in servers for soft, ver in s[3].items()],
        )

        plans = []   # (sv 행, 최종 상태)
        n = 0
        for system_id, hostname, env, installed, scenario in servers:
            for soft, ver in installed.items():
                for cve_id, status, fixed in cves[soft]:
                    if not is_affected(ver, status, fixed):
                        continue
                    n += 1
                    if scenario == "all_open":
                        final = "open"
                    elif scenario == "all_patched":
                        final = "patched"
                    else:
                        final = mixed_cycle[n % len(mixed_cycle)]
                    assignee = None if n % 4 == 0 else STAFF[n % len(STAFF)][0]   # 4건 중 1건은 담당자 없음
                    detected = now - timedelta(days=rng.randint(10, 40))
                    due = detected.date() + timedelta(days=rng.choice([7, 14, 30]))
                    if final == "open" and n % 3 == 0:
                        due = today - timedelta(days=rng.randint(1, 10))          # 기한 초과 미해결 건
                    plans.append(((system_id, cve_id, soft, assignee, due, detected), final, assignee))

        # 1) 모두 open으로 등록 (자동 탐지가 등록했다고 보고 updated_by = NULL) → INSERT 트리거가 이력 1건씩
        sv_ids = []
        for row, final, assignee in plans:
            cur.execute(
                "INSERT INTO system_vulnerabilities "
                "(system_id, cve_id, software_id, status, assignee_id, due_date, detected_at, updated_by) "
                "VALUES (%s, %s, %s, 'open', %s, %s, %s, NULL)",
                row,
            )
            sv_ids.append(cur.lastrowid)

        # 2) 최종 상태까지 단계별로 UPDATE → UPDATE 트리거가 단계마다 이력을 남긴다 (updated_by 반드시 함께)
        for sv_id, (row, final, assignee) in zip(sv_ids, plans):
            actor = assignee or 1
            steps = {"open": [], "in_progress": ["in_progress"], "patched": ["in_progress", "patched"],
                     "risk_accepted": ["risk_accepted"]}[final]
            for step in steps:
                if step == "patched":
                    cur.execute(
                        "UPDATE system_vulnerabilities SET status = 'patched', patched_at = %s, updated_by = %s "
                        "WHERE sv_id = %s",
                        (now - timedelta(days=rng.randint(0, 9)), actor, sv_id),
                    )
                else:
                    cur.execute(
                        "UPDATE system_vulnerabilities SET status = %s, updated_by = %s WHERE sv_id = %s",
                        (step, actor, sv_id),
                    )
    conn.commit()
    print(f"demo: 서버 {len(servers)}대, 담당자 {len(STAFF)}명, 조치 건 {len(plans)}건")


def make_bench(conn, software, cves, versions, n_servers, batch=1000):
    rng = random.Random(SEED)
    now = datetime.now().replace(microsecond=0)
    statuses = ["open", "in_progress", "patched", "risk_accepted"]
    old_weights = [3, 2, 90, 5]     # 탐지된 지 60일 넘은 건의 상태 비율(%)
    new_weights = [50, 25, 25, 0]   # 최근 60일 안에 탐지된 건의 상태 비율(%)

    with conn.cursor() as cur:
        cur.executemany("INSERT INTO staff (staff_id, name, team, email) VALUES (%s, %s, %s, %s)", STAFF)
    conn.commit()

    total_sv = 0
    for start in range(1, n_servers + 1, batch):
        ids = range(start, min(start + batch, n_servers + 1))
        systems, installed, sv_rows = [], [], []
        for system_id in ids:
            env = rng.choice(["prod", "prod", "staging", "dev"])
            systems.append((system_id, f"bench-{system_id:05d}", RELEASE, env))
            for soft in software:
                ver = rng.choice(versions[soft])
                installed.append((system_id, soft, ver))
                for cve_id, status, fixed in cves[soft]:
                    if not is_affected(ver, status, fixed):
                        continue
                    detected = now - timedelta(days=rng.randint(1, 365))
                    # 실제 운영처럼: 오래된 건은 대부분 끝났고, 최근 60일 안에 탐지된 건이 주로 미해결
                    weights = old_weights if (now - detected).days > 60 else new_weights
                    final = rng.choices(statuses, weights)[0]
                    due = detected.date() + timedelta(days=rng.choice([7, 14, 30, 60]))
                    patched_at = detected + timedelta(days=rng.randint(1, 30)) if final == "patched" else None
                    assignee = rng.choice([None, 1, 2, 3, 4])
                    sv_rows.append((system_id, cve_id, soft, final, assignee, due, detected, patched_at))
        with conn.cursor() as cur:
            # executemany + 단순 INSERT ... VALUES → PyMySQL이 여러 행 INSERT 한 문장으로 묶어서 보낸다 (빠름)
            cur.executemany(
                "INSERT INTO systems (system_id, hostname, ubuntu_release, environment) VALUES (%s, %s, %s, %s)",
                systems)
            cur.executemany(
                "INSERT INTO installed_software (system_id, software_id, installed_version) VALUES (%s, %s, %s)",
                installed)
            cur.executemany(
                "INSERT INTO system_vulnerabilities "
                "(system_id, cve_id, software_id, status, assignee_id, due_date, detected_at, patched_at) "
                "VALUES (%s, %s, %s, %s, %s, %s, %s, %s)",
                sv_rows)
        conn.commit()   # 배치마다 커밋: 중간에 멈춰도 앞부분은 남고, 트랜잭션이 너무 커지지 않는다
        total_sv += len(sv_rows)
        print(f"  서버 {ids[-1]}/{n_servers}대 적재")
    print(f"bench: 서버 {n_servers}대, 조치 건 {total_sv}건")


def main():
    parser = argparse.ArgumentParser(description="가상 데이터 생성")
    parser.add_argument("--mode", choices=["demo", "bench"], required=True)
    parser.add_argument("--servers", type=int, default=3000, help="bench 모드 서버 수")
    args = parser.parse_args()

    random.seed(SEED)
    conn = connect()
    try:
        with conn.cursor() as cur:
            software, cves, versions = load_real_data(cur)
        reset_synthetic(conn)
        if args.mode == "demo":
            make_demo(conn, software, cves, versions)
        else:
            make_bench(conn, software, cves, versions, args.servers)
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()


if __name__ == "__main__":
    main()

10영향 판정과 버전 비교

① 이 단계에서 만드는 것

"이 서버의 설치 버전이 이 CVE에 영향을 받는가?"를 판정하는 규칙. generate_synthetic.py의 is_affected()가 이 규칙이에요.

② 왜 이렇게 하나

  • 바이너리 ↔ 소스 패키지: 서버에 설치되는 건 openssh-server, openssh-client 같은 바이너리 패키지예요. Ubuntu CVE 상태는 소스 패키지 openssh 기준이에요. 그래서 software.source_package에는 소스 이름을 넣고, 설치 정보를 넣을 때 바이너리 → 소스로 바꿔요. USN의 release_packages에서 is_source: false인 항목들이 그 소스에서 나온 바이너리 목록이에요. Apache는 바이너리와 소스 이름이 둘 다 apache2예요.
  • 문자열 비교 금지: Debian 버전은 에포크:업스트림-데비안리비전 형식이라 글자 순서로 비교하면 틀려요. python-debian의 Version으로 비교해요. 그래서 DB에서는 버전 크기를 비교하지 않아요 (docs/db_dictionary.md 규칙).

③ 코드

from debian.debian_support import Version

# 예시용 버전 문자열 (실제 수정 버전 아님)
pairs = [
    ("2.4.58-1ubuntu8.9", "2.4.58-1ubuntu8.10"),   # 8.9 < 8.10 이어야 함
    ("1:9.6p1-3ubuntu13.5", "9.7p1-1"),            # 앞의 "1:"(epoch)가 있으면 항상 더 큼
    ("2.4.58-1ubuntu8", "2.4.58-1ubuntu8.1"),
]
for installed, fixed in pairs:
    print(f"{installed:22} < {fixed:20} | 문자열: {str(installed < fixed):5} | Version: {Version(installed) < Version(fixed)}")
# 영향 판정 규칙 (generate_synthetic.py의 is_affected)
#   status = needed   → 수정 버전이 아직 없음 → 영향 있음
#   status = released → Version(설치 버전) < Version(수정 버전) 이면 영향 있음
#   그 외 상태        → 조치 건을 만들지 않음

11(선택) dpkg-query 출력 적재

① 이 단계에서 만드는 것

data/load_dpkg.py — 실제 Ubuntu(VM 또는 WSL)에서 뽑은 설치 버전을 가상 서버 하나의 installed_software에 넣기.

② 왜 이렇게 하나

가상 데이터 중 하나라도 "진짜 서버에서 수집한 버전"이면 발표에서 "실제 운영에서는 이렇게 모은다"를 보여줄 수 있어요. ${source:Package} 필드가 바이너리 → 소스 매핑을 대신 해 줘요.

③ 코드

# Ubuntu에서 (패키지 이름은 확인하고 싶은 것만)
dpkg-query -W -f='${db:Status-Abbrev}\t${Package}\t${source:Package}\t${Version}\n' \
  openssh-server openssh-client apache2 > dpkg_web-prod-01.tsv
"""(선택) Ubuntu 서버의 dpkg-query 출력을 installed_software에 적재한다.

서버에서 먼저 실행:
  dpkg-query -W -f='${db:Status-Abbrev}\t${Package}\t${source:Package}\t${Version}\n' \
    openssh-server openssh-client apache2 > dpkg_web-prod-01.tsv
그다음:
  python data/load_dpkg.py --hostname web-prod-01 --file data/dpkg_web-prod-01.tsv
"""
import argparse

from load_db import connect


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--hostname", required=True)
    parser.add_argument("--file", required=True)
    args = parser.parse_args()

    found = {}   # source_package → 설치 버전
    with open(args.file, encoding="utf-8") as f:
        for line in f:
            parts = line.rstrip("\n").split("\t")
            if len(parts) != 4:
                continue
            status, package, source, version = parts
            if status.strip() != "ii":      # ii = 정상 설치됨. un(설치 안 됨) 등은 건너뜀
                continue
            # 바이너리 패키지(openssh-server, openssh-client)는 같은 소스 패키지(openssh)에서 나온다.
            # 같은 소스에서 나온 바이너리는 버전이 같으므로 하나만 남긴다.
            found[source] = version

    conn = connect()
    try:
        with conn.cursor() as cur:
            cur.execute("SELECT system_id FROM systems WHERE hostname = %s", (args.hostname,))
            row = cur.fetchone()
            if row is None:
                raise SystemExit(f"systems에 {args.hostname}가 없어요.")
            system_id = row[0]
            cur.execute("SELECT source_package, software_id FROM software")
            software_ids = dict(cur.fetchall())

            for source, version in found.items():
                if source not in software_ids:
                    continue
                # 이미 있으면 버전만 UPDATE (DELETE 후 INSERT 하면 조치 건의 복합 FK 때문에 실패)
                cur.execute(
                    "INSERT INTO installed_software (system_id, software_id, installed_version, collected_at) "
                    "VALUES (%s, %s, %s, NOW()) AS new "
                    "ON DUPLICATE KEY UPDATE installed_version = new.installed_version, collected_at = NOW()",
                    (system_id, software_ids[source], version),
                )
                print(f"{args.hostname}: {source} = {version}")
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()


if __name__ == "__main__":
    main()
