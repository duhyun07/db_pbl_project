CAUTION · 주의할 점

  • SQL을 문자열로 이어 붙이지 마세요. 항상 파라미터 바인딩(cursor.execute(sql, params)). 보안학과라 SQL Injection 질문이 나올 수 있어요.
  • 상태를 바꿀 때 updated_by도 같이 UPDATE해야 트리거가 이력에 변경자를 남겨요.
  • pymysql은 autocommit이 기본으로 꺼져 있어요. UPDATE 후 conn.commit()을 안 하면 연결을 닫을 때 변경이 사라져요 (실제로 확인: commit 없이 닫으면 상태가 그대로). 실패하면 conn.rollback().
  • Workbench에서 직접 테스트할 때: Safe Updates 모드(2주차)가 켜져 있으면 키가 아닌 컬럼 조건의 UPDATE가 막혀요. Error Code: 1175. You are using safe update mode and you tried to update a table without a WHERE that uses a KEY column. → WHERE sv_id = …처럼 키로 고르거나, 잠깐 SET SQL_SAFE_UPDATES = 0;
  • 쿼리는 직접 새로 쓰지 말고 ②의 query_catalog.json을 가져다 쓰기. 그래야 SQL 결과와 화면 숫자가 항상 같아요.
  • LLM은 SQL 결과 행만 근거로 요약하게 하고, 화면에 실행된 SQL 원문을 같이 보여주세요. API 키는 .env에만.
