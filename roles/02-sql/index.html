NOTE · 참고

분석 질문 후보

  1. 특정 서버에 관련된 취약점은?
  2. CVSS N점 이상인 미해결 취약점과 해당 서버·담당자는?
  3. 미해결 취약점이 있는 서버는 몇 대?
  4. Apache vs OpenSSH 취약점 수·위험도 분포는?
  5. 처리 기한을 넘긴 미해결 건과 담당자는?
  6. 서버별 패치 완료율은?
  7. 기간별 완료된 조치 건수는?

임계값(9.0 / 7.0)은 실제 데이터를 넣어 보고 정해요. Apache·OpenSSH엔 9점대 CVE가 생각보다 적을 수 있어요.

5~7번은 문제 페이지에 채점 문제(초안)로 있어요. 오늘 회의에서 질문이 확정되면 같이 고쳐요.

CASE 예시 (수업에 없던 문법)

SELECT cve_id, cvss_score,
       CASE
         WHEN cvss_score IS NULL THEN 'none'
         WHEN cvss_score >= 9.0  THEN 'critical'
         WHEN cvss_score >= 7.0  THEN 'high'
         WHEN cvss_score >= 4.0  THEN 'medium'
         ELSE 'low'
       END AS severity
FROM vulnerabilities
ORDER BY cve_id;
CVE-0000-0001 | 9.8  | critical
CVE-0000-0002 | 7.5  | high
CVE-0000-0003 | 5.3  | medium
CVE-0000-0004 | NULL | none
CVE-0000-0005 | 4.3  | medium

위에서부터 처음 맞는 WHEN 하나만 적용돼요. NULL을 맨 먼저 거르지 않으면 점수 없는 CVE가 low로 잘못 분류돼요 (seed 기준 결과).

CAUTION · 주의할 점

  • 집계 단위 주의: '서로 다른 CVE 수'(COUNT(DISTINCT cve_id)), '영향받는 서버 수'(COUNT(DISTINCT system_id)), '조치 건수'(COUNT(*))는 다른 숫자예요. 이걸 한 쿼리로 나란히 보여주면 발표에서 좋아요.
  • WHERE cvss_score >= 9는 CVSS가 NULL인 행을 조용히 빼요. NULL을 어떻게 다룰지 쿼리마다 정해 두세요.
  • 실행 시간은 한 번만 재지 말고 여러 번 재서 평균 내기. 측정 조건(데이터 크기, MySQL 버전)도 같이 적어 두세요.
  • EXPLAIN의 rows는 추정치예요 (7주차). 실제로 빨라졌는지는 EXPLAIN ANALYZE의 actual time이나 여러 번 잰 평균 시간으로 비교해요.
  • 인덱스 실험 대상: FK·UNIQUE 컬럼(system_id, cve_id, assignee_id 등)에는 이미 인덱스가 있어서 전후 비교를 해도 차이가 안 나요. cvss_score, status, due_date 같은 일반 컬럼으로 실험하세요. 후보 목록은 vuln-mgmt docs/design_decisions.md §6.
  • NOT IN 함정: 서브쿼리 결과에 NULL이 하나라도 있으면 NOT IN은 0건이 돼요. 예: staff_id NOT IN (SELECT assignee_id FROM system_vulnerabilities)는 assignee_id에 NULL(미배정)이 있어서 항상 0건. NOT EXISTS(11주차)를 쓰거나 서브쿼리에 WHERE assignee_id IS NOT NULL을 붙이세요.
  • 쿼리는 반드시 파라미터 자리(%s)로 써서 넘기기. ③이 문자열을 이어 붙이지 않게요.

CLASS · 수업 자료 먼저 보기

  • 7주차 EXPLAIN 해설 — table, type, possible_keys, key, rows(추정치), filtered, Extra. FK 인덱스로 ref를 찾는 예가 그대로 우리 인덱스 실험이에요 → 문제 #9
  • 10주차 GROUP BY·HAVING — 서버별 집계, 조건을 그룹에 거는 법 → 문제 #6, #7
  • 11주차 서브쿼리·EXISTS/NOT EXISTS·상관 쿼리 — "평균보다 많은 서버", NOT IN 함정, JOIN vs 상관 서브쿼리 비교 → 문제 #7
  • 수업에 없던 문법(CASE, COALESCE, NULLIF, SUM(조건식))은 공통 가이드 미니 사전
