CAUTION · 주의할 점

  • 집계 단위 주의: '서로 다른 CVE 수'(COUNT(DISTINCT cve_id)), '영향받는 서버 수'(COUNT(DISTINCT system_id)), '조치 건수'(COUNT(*))는 다른 숫자예요. 이걸 한 쿼리로 나란히 보여주면 발표에서 좋아요.
  • WHERE cvss_score >= 9는 CVSS가 NULL인 행을 조용히 빼요. NULL을 어떻게 다룰지 쿼리마다 정해 두세요.
  • 실행 시간은 한 번만 재지 말고 여러 번 재서 평균 내기. 측정 조건(데이터 크기, MySQL 버전)도 같이 적어 두세요.
  • 쿼리는 반드시 파라미터 자리(%s)로 써서 넘기기. ③이 문자열을 이어 붙이지 않게요.
